# VSCode shortcuts

## Multi-Cursor Editing
*remoting into Windows from macOS*
| Shortcut | Description |
| --- | --- |
| Ctrl + Opt + Shift + ↓ | Selects in a column directly up or down from the cursor's position |
| Opt + Click | add a new cursor at the mouse click |
| Ctrl + Shift + L | add new cursor behind all instances of a word |

## Comments 

| Shortcut | Description |
| --- | --- |
| Ctrl + / | Comments entire VS Code selection with single-line comments
